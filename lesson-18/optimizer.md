# 优化器原理

以线性回归为例推导各优化器。

## 符号说明

| 符号 | 含义 |
|------|------|
| lr (α) | 学习率 |
| β, β₁, β₂ | EMA 衰减系数，越大越"记忆"历史，越小越"遗忘" |
| ε | 防止除零的极小值，通常取 1e-8 |
| t | 当前训练步数（从 1 开始） |
| m | 一阶矩，梯度的 EMA（捕捉方向） |
| v | 二阶矩，梯度平方的 EMA（捕捉幅度） |

---

## SGD

**模型：** pred = a⋅x + b，损失：e = (pred - y)²

**梯度（链式法则）：**

    ∂e/∂pred = 2(pred - y) = 2(a⋅x + b - y)
    ∂pred/∂a = x
    ∂pred/∂b = 1
    ∂e/∂a = ∂e/∂pred * ∂pred/∂a = 2(a⋅x + b - y) * x
    ∂e/∂b = ∂e/∂pred * ∂pred/∂b = 2(a⋅x + b - y) * 1

**更新：**

    a(t) = a(t-1) - lr * ∂e/∂a
    b(t) = b(t-1) - lr * ∂e/∂b

**问题：** 梯度在不同 batch 间抖动，收敛慢，学习率难以选取。

---

## Momentum（EMA）

**思路：** 不直接用当前梯度，而是用梯度的指数移动平均（EMA）来平滑更新方向，抑制振荡。

    m_a(t) = m_a(t-1) * β + ∂e/∂a * (1 - β)
    a(t) = a(t-1) - lr * m_a(t)

    m_b(t) = m_b(t-1) * β + ∂e/∂b * (1 - β)
    b(t) = b(t-1) - lr * m_b(t)

**直觉：** 类似物理惯性，历史梯度累积，方向一致时加速，方向抖动时抵消。

> EMA 展开：m(t) = (1-β)·[g_t + β·g_{t-1} + β²·g_{t-2} + ...]
> 越近的梯度权重越大，呈指数衰减。典型值 β = 0.9。

---

## RMSProp

**思路：** 对每个参数自适应调整学习率——梯度大的方向步长缩小，梯度小的方向步长放大。

    ε = 1e-5 # very small value

    v_a(t) = v_a(t-1) * β + (∂e/∂a)^2 * (1 - β)
    a(t) = a(t-1) - lr * (∂e/∂a) / (sqrt(v_a(t)) + ε)

    v_b(t) = v_b(t-1) * β + (∂e/∂b)^2 * (1 - β)
    b(t) = b(t-1) - lr * (∂e/∂b) / (sqrt(v_b(t)) + ε)

**直觉：** sqrt(v(t)) 近似梯度的均方根（RMS），除以 RMS 使各参数有效步长自动均衡。
适合稀疏梯度或各特征量纲差异大的场景（如 RNN）。典型值 β = 0.99。

---

## Adam（Adaptive Moment Estimation）

**思路：** Momentum（一阶矩）+ RMSProp（二阶矩）+ 偏差修正。

    ε = 1e-5 # very small value

    m_a(t) = m_a(t-1) * β1 + ∂e/∂a * (1 - β1)    # 一阶矩：平滑梯度方向
    m_a(t) = m_a(t) / (1 - β1 ^ t)                # 偏差修正
    v_a(t) = v_a(t-1) * β2 + (∂e/∂a)^2 * (1 - β2) # 二阶矩：平滑梯度幅度
    v_a(t) = v_a(t) / (1 - β2 ^ t)                # 偏差修正
    a(t) = a(t-1) - lr * m_a(t) / (sqrt(v_a(t)) + ε)

    m_b(t) = m_b(t-1) * β1 + ∂e/∂b * (1 - β1)
    m_b(t) = m_b(t) / (1 - β1 ^ t)
    v_b(t) = v_b(t-1) * β2 + (∂e/∂b)^2 * (1 - β2)
    v_b(t) = v_b(t) / (1 - β2 ^ t)
    b(t) = b(t-1) - lr * m_b(t) / (sqrt(v_b(t)) + ε)

**为何需要偏差修正？**
初始化 m(0) = v(0) = 0，初期 t 小时 m(t)、v(t) 系统性偏小。
除以 (1 - β^t) 还原为无偏估计：t=1 时修正最大，t→∞ 时修正因子→1 自动消失。

**典型超参数：** lr = 1e-3，β₁ = 0.9，β₂ = 0.999，ε = 1e-8

---

## 对比总结

| 优化器 | 自适应学习率 | 动量 | 偏差修正 | 特点 |
|--------|:-----------:|:----:|:-------:|------|
| SGD | ✗ | ✗ | ✗ | 简单，需仔细调参 |
| Momentum | ✗ | ✓ | ✗ | 平滑更新，加速收敛 |
| RMSProp | ✓ | ✗ | ✗ | 适合稀疏梯度/RNN |
| Adam | ✓ | ✓ | ✓ | 大多数深度学习任务首选 |
